# 23篇经典英文演讲句集（手机适配版）

单页静态站点：21 个句集、207 句英文名言，点击句子播放真人发音并展开中文翻译。

## 特点

- 纯静态单文件 HTML，无构建依赖，双击即可在本地打开
- 手机适配：触控目标 ≥44px、安全区适配、字号与行距优化
- 语音每次点击只播放一遍（本地 MP3 优先，缺失时回退浏览器 TTS）
- 中文默认折叠，点句子展开／再点收起
- 左下角悬浮目录、右下角返回顶部，支持夜间模式

## 目录结构

```
index.html      主页面
audio/          207 段真人发音 MP3（微软神经网络语音）
.nojekyll       关闭 Jekyll 处理，保证静态资源原样发布
```
